# Originality boundary

Curty is an independent implementation created from a user-facing feature brief.

- No third-party source code, images, icons, names, layout constants, localization tables, or release scripts were copied.
- The implementation uses public Apple platform APIs, SF Symbols, and an original visual system.
- Contributors must keep all implementation and design work original or use material with an explicitly compatible license.
- If third-party code is added later, its license and required notices must be recorded before the change is accepted.

The application intentionally does not reproduce browser-wide Now Playing access because macOS does not expose that capability through a suitable public API.
