# Curty

Curty — самостоятельная утилита для macOS 15 и новее. Она объединяет полку файлов, историю буфера, сниппеты, календарь встреч, системный перевод, заметки и управление Music/Spotify.

## Установка

Нужен macOS 15 или новее и компилятор Swift:

```bash
xcode-select --install
```

Несмотря на название, эта команда ставит **не Xcode**, а Command Line Tools — компилятор, линкер и SDK, около полутора гигабайт. Само приложение Xcode на пятнадцать гигабайт для сборки Curty не нужно.

Затем:

```bash
git clone https://github.com/AYSGODX/Curty.git
cd Curty
Scripts/install.sh
```

Скрипт соберёт приложение, положит его в «Программы» и запустит. В строке меню появится иконка щита, а сама панель раскрывается при наведении курсора на вырез экрана.

При первом открытии вкладки «Медиа» macOS спросит разрешение на управление Spotify или Music.

Приложение, собранное на своей машине, не имеет карантинного атрибута, поэтому Gatekeeper его не блокирует и обходить ничего не нужно.

## Обновление

```bash
git pull && Scripts/install.sh
```

Данные не теряются: заметки, сниппеты, полка и настройки лежат в контейнере приложения и привязаны к его идентификатору, а не к файлу приложения.

Разрешение на управление плеером после обновления придётся выдать заново. Подпись локальной сборки привязана к содержимому бинарника, поэтому после пересборки macOS считает приложение новым. Это устраняется только сертификатом Developer ID.

## Приватность и безопасность

Curty работает в песочнице macOS: прочитать файл, который вы не выбрали сами, он не может — это ограничение системы, а не обещание приложения. История буфера и события календаря живут только в памяти. Заметки, сниппеты и ссылки полки лежат в контейнере приложения с правами `0600`.

Единственный сетевой запрос — загрузка обложки играющего трека по ссылке, которую сообщает сам плеер. Телеметрии, аналитики и автообновления нет.

Границы держит не это описание, а [`Scripts/security-check.sh`](Scripts/security-check.sh). Он валит сборку, если сетевой код появится где-нибудь кроме `ArtworkLoader.swift`, если оттуда пропадёт список разрешённых хостов, или если в проекте всплывут приватные фреймворки, `dlopen` или синтез событий ввода. Скрипт запускается на каждой сборке, поэтому смотреть действующие правила стоит прямо в нём: он не может разойтись с кодом, а текст — может.

## Локальная сборка

```bash
Scripts/security-check.sh
swift test --disable-sandbox
Scripts/build-app.sh release
ALLOW_DEVELOPMENT_SIGNATURE=1 Scripts/verify-release.sh .build/Products/Curty.app
```

Команда создаёт локально подписанную сборку в `.build/Products/Curty.app`. Она подходит для проверки на этом Mac, но не для передачи другим людям.

## Передача другим людям

Поделиться проще всего исходниками: получатель собирает его у себя по инструкции выше, и вопрос подписи не возникает вовсе.

Код распространяется под лицензией MIT, см. [LICENSE](LICENSE).

Готовый бинарник — другое дело. Ad-hoc сборку передавать нельзя: скачанный файл получает карантинный атрибут, и Gatekeeper откажется его запускать, потому что подтвердить происхождение нечем. Для раздачи собранного приложения нужны Apple Developer ID, hardened runtime и нотаризация — команды собраны в [docs/RELEASE.md](docs/RELEASE.md).
