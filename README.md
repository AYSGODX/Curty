# Curty

Curty — самостоятельная утилита для macOS 15 и новее. Она объединяет полку файлов, историю буфера, сниппеты, календарь встреч, системный перевод, заметки и управление Music/Spotify.

## Приватность

- История буфера и управление медиаплеерами включены по умолчанию.
- Доступ к календарю запрашивается только после нажатия отдельной кнопки.
- Изображения буфера остаются в памяти, пока пользователь явно не сохранит их на полку.
- Файлы за пределами контейнера доступны только через выбранные пользователем security-scoped bookmarks.
- Управление Music/Spotify использует только фиксированный набор AppleScript-команд.
- Используются только публичные API Apple; браузерное Now Playing намеренно не реализовано.

## Локальная сборка

```bash
Scripts/security-check.sh
swift test --disable-sandbox
Scripts/build-app.sh release
ALLOW_DEVELOPMENT_SIGNATURE=1 Scripts/verify-release.sh .build/Products/Curty.app
```

Команда создаёт локально подписанную сборку в `.build/Products/Curty.app`. Она подходит для проверки на этом Mac, но не для передачи другим людям.

## Безопасная передача

Для распространения используйте Apple Developer ID, hardened runtime и notarization. Инструкция и необходимые команды находятся в `docs/RELEASE.md`. Не передавайте ad-hoc сборку как готовый релиз: Gatekeeper не сможет подтвердить её происхождение.
